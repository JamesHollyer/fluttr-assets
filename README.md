# fluttr-assets

Downloadable files for the Fluttr bird watching app, published as release assets.

- `model-perch-v2-int8-*`: the on-device Sound ID model. It is Google's Perch v2 bird
  vocalization classifier (Apache License 2.0), converted to ONNX with its dense head
  quantized to int8. See the release notes for the source and the license.

Nothing here is code; the app lives in a separate repository.
